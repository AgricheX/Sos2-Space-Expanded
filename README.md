## English

### What it adds

- Antimatter ship parts: reactor, void engine and heat capacity.
- Antimatter kinetic turrets, projectiles and bombs.
- A new ship bridge.
- Nemesis ships.

### How to install

1. Install Save Our Ship 2.
2. Download **Sos2SpaceExpanded.zip** with the link above, or subscribe on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3536311507).
3. Extract it into the `Mods` folder of your RimWorld installation, so you get `Mods/Sos2 Space Expanded/About/About.xml`.
4. Enable it in the mod list and load it after Save Our Ship 2.

## Português (Brasil)

### O que o mod adiciona

- Peças de nave de antimatéria: reator, motor do vazio e capacidade térmica.
- Torretas cinéticas, projéteis e bombas de antimatéria.
- Uma nova ponte de comando.
- Naves Nemesis.

### Como instalar

1. Instale o Save Our Ship 2.
2. Baixe o **Sos2SpaceExpanded.zip** pelo link acima, ou inscreva-se na [Oficina da Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3536311507).
3. Extraia na pasta `Mods` do RimWorld, de forma que fique `Mods/Sos2 Space Expanded/About/About.xml`.
4. Ative na lista de mods e carregue depois de Save Our Ship 2.

### Ajuda

Dúvidas e bugs: [Agriche Community no Discord](https://discord.gg/s3EbgNSsJW).
